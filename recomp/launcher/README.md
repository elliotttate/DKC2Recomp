# Launcher artwork

`boxart.tga` is the North American retail cover for *Donkey Kong Country 2:
Diddy's Kong Quest*. It is used only to identify the game and supported ROM
region in the pre-boot launcher.

Source image:
[`libretro-thumbnails/Nintendo_-_Super_Nintendo_Entertainment_System`](https://github.com/libretro-thumbnails/Nintendo_-_Super_Nintendo_Entertainment_System/blob/master/Named_Boxarts/Donkey%20Kong%20Country%202%20-%20Diddy's%20Kong%20Quest%20%28USA%29%20%28En%2CFr%29.png)

The source PNG was resized from 512 x 357 to 378 x 263 pixels and converted to
uncompressed RGB TGA for `recomp-ui`. No creative changes were made.

The cover art and associated trademarks remain copyright Nintendo and Rare.
DKC2Recomp claims no ownership and includes the image solely for game and
region identification.
